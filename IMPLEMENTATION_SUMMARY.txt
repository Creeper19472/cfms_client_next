manages file downloads in the CFMS Client application. The service 
provides a unified interface for queuing, monitoring, and controlling 
multiple concurrent downloads through a dedicated "Tasks" view.

───────────────────────────────────────────────────────────────────────
USAGE EXAMPLES
───────────────────────────────────────────────────────────────────────

FOR USERS:
  1. Navigate to Files view
  2. Click file to download
  3. Switch to Tasks view (nav bar index 1)
  4. Monitor download progress
  5. Cancel if needed
  6. Clear completed tasks

FOR DEVELOPERS:
  # Get service
  service = AppShared().service_manager.get_service("download_manager")
  
  # Add task
  task = service.add_task(task_id, file_id, filename, file_path)
  
  # Monitor
  service.add_task_update_callback(callback)
  
  # Cancel
  service.cancel_task(task_id)
